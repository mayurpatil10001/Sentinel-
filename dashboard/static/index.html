Security & audit

Audit & Evidence Access Log

GET /api/audit/evidence-access
Every row is written automatically by build_evidence_log() — one row per pull of alert evidence. Logs who pulled what, when, and whether raw account IDs were returned.
Raw ID access (used_raw_ids=true) indicates an analyst explicitly requested unhashed account IDs. This is expected for SEBI/exchange verification workflows but should be reviewed.
