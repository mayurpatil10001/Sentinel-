Scientific & Empirical Honesty Disclosure

Every threshold is labelled transparently as UNVALIDATED_HEURISTIC. No SEBI order number, date, or URL has been verified as the source for any numeric threshold. Sentinel cannot detect order-book spoofing, layering, circular trading, or coordinated manipulation without order/account-level data for all market participants (not available via broker APIs). An alert is a statistical outlier — not a finding of manipulation. No false-positive rate has been empirically measured against confirmed cases.
